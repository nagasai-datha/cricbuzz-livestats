STEP 2 — VIDEO RECORDING (Required by Labmentrix)
================================================================

Use Xbox Game Bar (built into Windows 11):

1. Make sure your app is running (streamlit run main.py)
2. Press  Windows key + G  → Xbox Game Bar opens
3. Click the Record button OR press  Win + Alt + R
4. Record these pages in order:
   → Home page (scroll down slowly)
   → Live Matches (show live scores)
   → Player Stats (change format to Test, show chart)
   → SQL Analytics (run Q1, Q3, Q5, Q17)
   → CRUD Operations (add a player, show it in table)
5. Press  Win + Alt + R  again to stop
6. Video saves to: C:\Users\nagas\Videos\Captures\

Recording tips:
→ Record for 3-5 minutes total
→ Click each page slowly so viewer can see
→ Run at least 4-5 SQL queries
